# Quest Progress

## Назначение
`QuestProgress` представляет собой прохождение конкретного Quest конкретной командой.

QuestProgress является runtime-сущностью игрового прохождения.
Активное прохождение существует во время проведения Quest.
После завершения Quest QuestProgress сохраняется как история прохождения и используется для формирования итоговой статистики и результатов.

---

# Жизненный цикл

```
Quest
        │
        ▼
QuestRegistration (APPROVED)
        │
        ▼
QuestProgress
        │
        ▼
LevelProgress
```

---

# Создание
QuestProgress создаётся автоматически при выполнении двух условий.

1. Quest находится в состоянии
```
RUNNING
```

2. Регистрация команды имеет статус
```
APPROVED
```

Если регистрация подтверждена до начала Quest,
QuestProgress будет создан автоматически в момент старта Quest.

Если регистрация подтверждена после старта Quest,
QuestProgress создаётся сразу после подтверждения.

---

# Один QuestProgress
Для каждой команды существует только один QuestProgress для одного Quest.
Повторное создание невозможно.

---

# Игровое время
Игровое время определяется исключительно временем начала Quest.

Пример.
Quest стартовал
```
21:00
```

Команда вошла
```
21:25
```

Это означает, что команда уже потеряла 25 минут игрового времени.
Таймер первого уровня показывает оставшееся время, а не начинает отсчёт заново.
Таким образом опоздание не даёт никаких преимуществ.

---

# Первый уровень
Первый `LevelProgress` создаётся в момент первого входа команды в Quest.
Создание `QuestProgress` и создание первого `LevelProgress` являются разными событиями.
`QuestProgress` может находиться в статусе `WAITING`, пока команда ещё не вошла в игру.
Если первый уровень имеет автопереход, команда, вошедшая позже, получает только оставшееся время до автоперехода.
Если время автоперехода уже закончилось, команда мгновенно переходит на следующий уровень.

Для первого уровня:
autoTransitionAt = Quest.startTime + Level.autoTransition

Для последующих:
autoTransitionAt = LevelProgress.openedAt + Level.autoTransition
---

# Последующие уровни
Все остальные LevelProgress создаются только после завершения предыдущего уровня.
Следующий уровень никогда не может существовать, пока предыдущий уровень не завершён.

---

# Завершение уровня
LevelProgress завершается одним из способов.
```
CODES
```

Команда ввела необходимое количество правильных кодов.

---

```
AUTO_TRANSITION
```

Истекло время автоперехода.

---

# Порядок уровней
Команда никогда не может иметь одновременно несколько активных игровых уровней.
В каждый момент времени существует ровно один активный LevelProgress.

---

# Завершение Quest
QuestProgress считается завершённым после прохождения последнего уровня:
статус:
```
FINISHED
```

или, в случае, если команда не финишировала (прекратила игру по любым причинам) получением командой статуса:
```
DNF
```
выставляется автоматически для всех не финишировавших команд, в момент выставления автором статуса 
```
FINISHED
```

После завершения фиксируется
- время прохождения;
- бонусное время;
- штрафное время;
- итоговое время;
- итоговый статус.

---

## Время

`QuestProgress.questStartedAt` всегда соответствует времени старта Quest.
`QuestProgress.enteredAt` фиксирует фактический момент первого входа команды.
`enteredAt` не влияет на начало игрового времени.

---

# Повторное прохождение
QuestProgress является одноразовым объектом.
После завершения Quest команда больше не может начать его повторно.
История прохождения сохраняется навсегда.

---

# Инварианты QuestProgress
- Один QuestProgress принадлежит только одной команде.
- Один QuestProgress относится только к одному Quest.
- Игровое время никогда не зависит от времени входа команды в игру.
- Первый уровень всегда начинается относительно времени старта Quest.

## Инварианты LevelProgress
- LevelProgress принадлежит QuestProgress.
- Каждый LevelProgress относится к одному Level.
- Одновременно у команды может быть только один активный LevelProgress.
- Первый LevelProgress создаётся при первом входе команды.
- Следующий LevelProgress создаётся только после завершения предыдущего.
- openedAt — фактическое время открытия уровня для команды.
- Для первого уровня autoTransitionAt считается от Quest.startTime. Для остальных — от openedAt.
- Если autoTransitionAt уже прошло в момент открытия/входа — уровень сразу считается пройденным по автопереходу.
- Автопереход не даёт команде дополнительного времени.
