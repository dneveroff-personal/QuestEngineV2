# Domain Events

## Назначение
Domain Events описывают все значимые события, происходящие в системе.
События отражают бизнес-логику движка и являются единым способом уведомления остальных компонентов системы о произошедших изменениях.
Одно событие описывает один завершённый бизнес-факт.

---

# Quest Events

## QuestCreated
Автор создал новый Quest.

---

## QuestPublished
Quest опубликован и открыт для регистрации команд.

---

## QuestUpdated
Автор изменил параметры Quest.

---

## QuestStarted
Наступило время старта Quest.
Игровое время начинает отсчёт.

---

## QuestFinished
Quest завершён.
Итоговая статистика зафиксирована.

---

# Principles
Каждое событие описывает завершённый факт.
События никогда не изменяются после публикации.
Каждое событие имеет время возникновения.
Каждое событие относится к одному Quest.

Каждое событие может использоваться для:
- обновления статистики;
- уведомления игроков;
- записи истории;
- аудита;
- интеграции с другими сервисами.
