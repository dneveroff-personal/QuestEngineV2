# Quest Registration

## Назначение
`QuestRegistration` описывает процесс регистрации команды на конкретный Quest.
Данная сущность не относится к игровому процессу. Она существует исключительно для организации участия команды в квесте.
Регистрация отделена от игрового процесса намеренно.
Даже если команда зарегистрирована, это не означает, что она будет допущена к игре.

---

# Жизненный цикл

```
Team
    │
    ▼
QuestRegistration
    │
    ├── PENDING
    ├── APPROVED
    ├── CANCELLED
    └── REJECTED
            │
            ▼
QuestProgress (если Quest уже запущен)
```

---

# Создание
Регистрация создаётся в момент, когда капитан команды нажимает кнопку «Подать заявку».
При этом создаётся объект QuestRegistration.

Статус регистрации:
```
PENDING
```

---

# Подтверждение
Регистрацию подтверждает только автор Quest.
После подтверждения статус становится

```
APPROVED
```

До подтверждения команда не является участником игры.

---

# Подтверждение после старта

Автор может подтвердить участие даже после официального старта Quest.
В этом случае QuestProgress создаётся сразу после подтверждения.
При этом команда начинает игру с уже идущим игровым временем.

Иными словами:
Старт игры определяется временем начала Quest, а не временем подтверждения команды.
Это позволяет автору принимать команды непосредственно на месте старта.

---

# Ограничение количества команд
Quest может иметь ограничение на количество подтверждённых команд.
Количество команд со статусом `APPROVED` не может превышать установленный лимит.
Поведение новых заявок при достижении лимита - разрешить заявку, но запретить подтверждение;


---

# Закрытие регистрации
Автор может выбрать один из вариантов:
- регистрация закрывается автоматически в момент старта;
- регистрация закрывается в указанное время;
- регистрация открыта до ручного закрытия автором.

---

# Отмена регистрации
Команда может отменить свою заявку самостоятельно,
пока она находится в статусе

```
PENDING
```

После подтверждения регистрация становится окончательной.

---

# Неявка команды
Если команда была подтверждена,
но не приступила к прохождению Quest, после завершения игры она получает статус

```
DNF
```

(Did Not Finish)

История участия при этом сохраняется.

---

# Удаление команды
После подтверждения регистрации автор не может удалить команду из Quest.
В процессе игры автор может применять только игровые санкции (например штрафное время).

История участия является неизменяемой.
