# Team

## Назначение

`Team` представляет группу пользователей, объединённых для совместного участия в Quest.

Команда является постоянной сущностью системы.

Команда может существовать независимо от каких-либо игр.

---

## Жизненный цикл

Команда может существовать длительное время и участвовать во множестве Quest.

Например:

```text
Team A
 ├── QuestProgress #1
 ├── QuestProgress #2
 └── QuestProgress #3
```

После завершения всех игр команда продолжает существовать.

Удаление команды обычным пользователем не предусмотрено.

Администратор системы может иметь отдельное административное право удаления или блокировки команды.

---

## Состав команды

Team состоит из пользователей.

Один пользователь не может одновременно состоять более чем в одной команде.

Следовательно:

```text
User
  ↓
0..1 Team
```

Пользователь может существовать без команды.

---

## Капитан команды

В каждой команде обязательно существует капитан.

Команда не может существовать без капитана.

Капитан является участником команды с дополнительными полномочиями.

---

## Полномочия капитана

Капитан может:

* подавать заявки команды на Quest;
* отправлять приглашения игрокам;
* принимать приглашения;
* принимать заявки игроков на вступление;
* переименовывать команду;
* передавать права капитана.

---

## Передача капитанства

Капитан может передать свои права другому участнику команды.

После передачи:

```text
Old Captain → Team Member
New Captain → Team Captain
```

В команде всегда остаётся ровно один капитан.

---

## Выход капитана

Капитан не может покинуть команду, если в результате команда останется без капитана.

Перед выходом капитан должен передать капитанство другому участнику.

Если капитан является последним участником команды, он не может покинуть команду.

---

## Переименование

Капитан может изменить название команды.

Изменение названия не создаёт новую команду.

Идентичность команды определяется её `Team.id`.

```text
Team #42

Old name:
Night Wolves

New name:
Night Wolves 2.0
```

Это остаётся той же самой командой:

```text
Team.id = 42
```

История участия команды в Quest сохраняется.

---

## Команда и Quest

Команда может существовать без активных игр.

Команда может участвовать в нескольких Quest одновременно.

Нет ограничения:

```text
Team → one active Quest
```

Одна команда может одновременно иметь несколько активных `QuestProgress`.

Например:

```text
Team A

QuestProgress #1 — автомобильный Quest
QuestProgress #2 — онлайн Quest
QuestProgress #3 — дополнительный Quest
```

Каждый `QuestProgress` независим.

---

## Участие в Quest

Только капитан может подавать заявку от имени команды.

Обычный участник команды не может самостоятельно зарегистрировать команду на Quest.

Заявка создаётся через:

```text
QuestRegistration
```

Автор Quest отдельно подтверждает заявку.

---

## Captain и Author

`Team Captain` и `Quest Author` — разные полномочия.

Один пользователь может одновременно обладать обоими.

Например:

```text
User #42

Team Captain
+
Author of Quest #15
```

В таком случае:

* при подаче заявки своей команды действует как `Team Captain`;
* при управлении собственным Quest действует как `Author`.

Наличие статуса Author само по себе не даёт права подавать заявки от имени команды.
