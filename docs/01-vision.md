QuestEngine — серверная платформа для проведения интеллектуальных командных соревнований в реальном времени.

### Основные принципы:
- несколько команд одновременно;
- честное соревнование;
- все проходят один и тот же Quest;
- каждая команда имеет собственное состояние прохождения;
- автор описывает игру только один раз.
