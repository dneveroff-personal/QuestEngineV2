# Frontend Screens

## 1. Главная — Home

Главная страница является стартовой страницей приложения для любого пользователя.

Доступна без авторизации.

Содержит:

- текущие квесты;
- предстоящие квесты;
- краткую информацию о каждом квесте;
- основную навигацию;
- кнопку входа / регистрации для неавторизованного пользователя.

После авторизации содержимое главной страницы остаётся тем же,
но пользователь получает доступ к персональным действиям.

---

## 2. Страница квеста — Quest

URL:

`/quests/{questId}`

Страница доступна как авторизованным, так и неавторизованным пользователям.

### Информация

Отображается:

- название;
- описание;
- тип;
- автор;
- дата и время начала;
- дата и время окончания, если задана;
- максимальное количество команд;
- стоимость участия, если указана;
- список команд, подавших заявку;
- список команд, подтверждённых автором.

### Действия

Действия зависят от состояния пользователя и его команды.

Неавторизованный пользователь:

- может просматривать страницу;
- не может подать заявку;
- не может войти в игру.

Авторизованный пользователь:

- может просматривать страницу;
- если является капитаном — может подать заявку от имени команды;
- если его команда уже участвует — видит состояние участия.

Подтверждённая команда после начала Quest:

`Войти в игру`

---

## 3. Мои квесты — My Quests

URL:

`/my-quests`

Доступна только авторизованному пользователю.

Содержит:

### Текущие

Квесты, в которых команда пользователя принимает участие
и которые ещё не завершены для неё.

### Прошедшие

Квесты, в которых команда пользователя ранее участвовала.

Для каждого отображается:

- название;
- дата игры;
- команда;
- статус;
- результат;
- итоговое место, если доступно.

---

## 4. Команда — Team

URL:

`/team`

Доступна авторизованному пользователю.

Отображает:

- название команды;
- капитана;
- участников;
- дату создания;
- историю / статистику команды;
- результаты игр.

### Для обычного участника

Доступны:

- просмотр состава;
- просмотр информации о команде;
- просмотр статистики;
- выход из команды.

### Для капитана

Дополнительно доступны:

- изменение названия;
- управление составом;
- принятие / отклонение приглашений;
- обработка заявок игроков;
- приглашение игроков;
- передача капитанства.

Капитан не может покинуть команду, если после его ухода
команда останется без капитана.

---

## 5. Профиль — Profile

URL:

`/profile`

Содержит:

- личную информацию пользователя;
- историю участия в квестах;
- результаты;
- статистику;
- послужной список;
- информацию об авторских квестах, если пользователь является автором.

---

## 6. Авторская — Author

URL:

`/author`

Доступна пользователям, имеющим право создавать и редактировать квесты.

Содержит:

- созданные квесты;
- квесты в разработке;
- завершённые квесты;
- управление существующими квестами;
- кнопку `Создать квест`.

---

## 7. Редактор квеста — Quest Editor

URL:

`/author/quests/{questId}/edit`

Предназначен для создания и редактирования Quest.

Основные разделы:

- основная информация;
- настройки игры;
- уровни;
- коды;
- подсказки;
- команды;
- регистрация участников;
- управление игрой;
- статистика.

Редактор должен позволять автору работать с квестом
как с единым объектом, не заставляя его перемещаться между
несвязанными административными страницами.

---

## 8. Управление командами квеста

URL:

`/author/quests/{questId}/teams`

Автор видит:

- команды, подавшие заявку;
- подтверждённые команды;
- количество свободных мест;
- статус каждой команды.

Автор может:

- подтвердить заявку;
- отклонить заявку;
- управлять участием подтверждённой команды;
- завершить игру;
- назначать ручные штрафы / бонусы в соответствии с правилами игры.

После подтверждения команды удалить её из игры нельзя.

---

## 9. Игровой экран — QuestProgress

URL:

`/quests/{questId}/play`

Это отдельный игровой интерфейс.

Обычная навигация приложения здесь отсутствует.

Главная задача интерфейса:

> Команда должна максимально быстро понимать,
> что ей сейчас нужно делать.

На экране отображаются:

- текущий уровень;
- содержание уровня;
- таймер;
- поле ввода кода;
- результат отправки кода;
- доступные подсказки;
- состояние прохождения уровня;
- переход к следующему уровню.

Игровой экран не должен выглядеть как обычная административная
или информационная страница приложения.

---

## 10. Статистика игры — Quest Statistics

URL:

`/quests/{questId}/statistics`

Статистика доступна с момента начала игры.

Она отображается в реальном времени.

Основное представление — таблица:

- строки / колонки уровней;
- команды;
- порядок прохождения уровней;
- текущий итоговый результат.

В процессе игры результат является предварительным.

После завершения игры результат становится финальным.

Статистика должна позволять понять:

- кто сейчас впереди;
- сколько уровней прошла каждая команда;
- в каком порядке команды проходили уровни;
- какое место занимает команда;
- какое итоговое время получается с учётом бонусов и штрафов.

# Навигация

## Обычный пользователь

Главное меню:

- Мои квесты
- Команда
- Профиль

## Автор

Главное меню:

- Мои квесты
- Команда
- Профиль
- Авторская

## Капитан

Использует тот же интерфейс, что и обычный игрок.

Дополнительные действия появляются внутри страницы `Команда`.

## Администратор

Имеет доступ ко всем соответствующим разделам.

---

# Игровой режим

Игровой режим является отдельным UI-контекстом.

После перехода в QuestProgress:

- обычное главное меню скрывается;
- пользователь не должен отвлекаться на функции приложения;
- основное пространство занимает текущий уровень;
- таймер является одним из наиболее важных элементов интерфейса.

Выход из игрового режима должен быть явным действием,
например:

- `Статистика`;
- `Выйти из игры`;
- `Вернуться к квесту`.

Конкретный набор действий будет определён отдельно.
