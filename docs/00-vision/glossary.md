# Quest
Описание игры, создаваемое автором.
Содержит уровни, коды, подсказки, настройки игры и время старта.
Сам по себе Quest никогда не изменяется во время игры, это сценарий по которому проходит квест.


# Level
Описание одного игрового этапа.
Может содержать:
- текст задания;
- коды;
- подсказки;
- автопереход;
- требуемое количество правильных кодов.


# Team
Команда игроков (Users).
Команда может одновременно участвовать в нескольких различных Quest.


# User 
Пользователь сайта. Чтобы принять участие в командном квесте, должен вступить в существующую команду или создать новую, заняв место капитана и пригласив к себе в команду других пользователей.


# QuestRegistration
Регистрация команды на Quest.
Создается после подачи заявки.
Хранит:
- дату регистрации;
- статус заявки;
- команду;
- Quest

QuestRegistration
│
│ APPROVED
│
▼
QuestProgress

То есть Registration остаётся историей регистрации, а Progress — историей/состоянием игры.


# QuestProgress
Runtime-сущность.
Описывает прохождение Quest одной конкретной командой.
Содержит:
- текущий уровень;
- время начала;
- время окончания;
- статус;
- список LevelProgress. 
 

# LevelProgress
Runtime-сущность.
Описывает прохождение конкретного уровня конкретной командой.
Содержит:
- статус;
- время начала;
- время окончания;
- найденные коды;
- использованные подсказки;
- штрафы;
- бонусы.


# CodeSubmission
Попытка ввода кода.
Даже неправильные попытки логируются.


# HintUsage
Факт получения подсказки.


# Author
Роль назначаемая администратом игроку.
Данный игрок может создавать и управлять сущностями Quest и QuestRegistration.
Автор этот тот, кто создает и проводит квесты от создания до завершения.


# Captain
Роль игрока в команде, который подает заявки на игру и управляет составом команды.


# DNF
Статус команды не дошедшей до финиша в игре. 


# Auto-transition
Автопереход. Автоматическое завершение уровня при достижении отведенного времени на прохождение уровня командой. 


# Bonus Time
Бонусное время измеряемое секундами, которое может быть начислено команде как вручную автором, так и автоматически за ввод "бонусных кодов"


# Penalty Time
Штрафное время измеряемое секундами, которое может быть начислено команде как вручную автором, так и автоматически за ввод "штрафных кодов"
