# ADR-0001 — Quest is the Core Domain Object

## Status

Accepted

## Context

Quest Engine предназначен для проведения соревнований между командами.

Все остальные сущности системы существуют только в контексте конкретного Quest.

Команды регистрируются на Quest.

Уровни не существуют сами по себе — они принадлежат Quest.

Коды принадлежат Level.

Подсказки принадлежат Level.

Статистика относится к прохождению Quest.

Таким образом, именно Quest является центральной сущностью предметной области.

## Decision

Quest является главным агрегатом (Aggregate Root) предметной области.

Все остальные сущности проектируются относительно Quest.

Основные связи:

Quest
├── Levels
├── Registrations
├── QuestProgress
├── Statistics
└── Metadata

## Consequences

Преимущества:

- единая точка входа в модель;
- простая навигация по предметной области;
- отсутствие неоднозначности при проектировании.

Это решение становится частью Ubiquitous Language проекта.
