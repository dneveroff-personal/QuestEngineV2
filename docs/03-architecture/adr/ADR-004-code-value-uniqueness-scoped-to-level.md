# ADR-0004 — Code Value Uniqueness Is Scoped To Level

## Status

Accepted

## Context

`CodeServiceImpl.validateCodeValueUnique` в текущей реализации проверяет уникальность `code_value` глобально по всей базе данных, а не в пределах одного Level.

Это техническое ограничение, оставшееся от первоначальной реализации CRUD для `Code`, не являлось осознанным продуктовым решением.

Следствие: два разных автора (или один автор на двух разных уровнях/квестах) не могут использовать одинаковый простой код (например, `"1234"`), даже если уровни никак не связаны и никогда не пересекутся в рамках одной игры.

Encounter и аналогичные движки этого класса не накладывают такого ограничения — коды уникальны в рамках уровня, не всей системы.

Зафиксировано как открытый вопрос в `01-domain/code-submission.md`.

## Decision

Уникальность `code_value` проверяется **в пределах одного Level**, а не глобально.

Технически: составной уникальный индекс `(level_id, code_value)` вместо текущего `UNIQUE(code_value)`. Проверка на дубликат при создании/редактировании кода выполняется через `existsByLevelIdAndCodeValue`, а не `existsByCodeValue`.

Требуется миграция схемы БД (снять старое ограничение уникальности, добавить новое составное).

## Consequences

Преимущества:
- Авторы могут переиспользовать простые, запоминающиеся коды между разными уровнями и квестами.
- Соответствует практике движков этого класса.

Издержки:
- Требуется миграция схемы для уже существующих данных (на момент принятия решения — до продакшен-данных, миграция не имеет рисков потери данных).
