# Domain Invariants

- Один пользователь одновременно может состоять только в одной команде.
- Команда существует независимо от Quest.
- Quest всегда начинается в указанное автором время.
- QuestProgress создаётся для подтверждённой команды:
    - при старте Quest, если регистрация уже имеет статус APPROVED;
    - в момент подтверждения регистрации, если Quest уже запущен.
- Время старта Quest является общим для всех команд и не зависит от момента создания QuestProgress.- Повторное прохождение Quest одной и той же командой невозможно.
- LevelProgress существует только внутри QuestProgress.

# Team Domain Rules

## Team
Команда — это постоянная сущность предметной области.
Команда создаётся пользователями и существует независимо от Quest.
Команда может существовать без активных или завершённых игр.
Удаление команды пользователями не предусмотрено.

## Captain
В каждой команде всегда существует ровно один капитан.
Команда не может существовать без капитана.
Если капитан хочет покинуть команду, он обязан сначала передать капитанство другому участнику.
Если капитан является единственным участником команды, выход из команды невозможен.

## Membership
Пользователь одновременно может состоять только в одной команде.
Переход в другую команду возможен только после выхода из текущей команды.

## Team Name
Название команды не является идентификатором.
Команда может менять название неограниченное количество раз.
Идентичность команды определяется только её ID.

## User Roles
Роли и полномочия пользователя не являются взаимоисключающими.

Один User может одновременно быть:
- участником команды;
- капитаном команды;
- автором одного или нескольких Quest;
- администратором.

В частности, капитан команды может одновременно являться автором Quest.
Полномочия определяются контекстом выполняемого действия.

Например:
- при подаче заявки действует полномочие `Team Captain`;
- при подтверждении заявки действует полномочие `Quest Author`;
- при редактировании собственного Quest действует полномочие `Quest Author`.
