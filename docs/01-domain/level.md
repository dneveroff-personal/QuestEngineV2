# Level

## Назначение
Level представляет собой одно игровое задание Quest.
Quest состоит из последовательности Level.
Каждый Level описывается автором Quest и является частью шаблона игры.
Во время прохождения игры каждая команда получает собственный экземпляр прохождения уровня — `LevelProgress`.

---

# Структура
Каждый Level содержит:
- название;
- описание задания;
- порядковый номер;
- список кодов;
- список подсказок;
- настройки прохождения.

---

# Порядок
Level всегда принадлежит одному Quest.
Порядок прохождения определяется номером уровня.
После начала Quest структура и порядок уровней не изменяются.

---

# Коды
Level может содержать любое количество игровых кодов.
Коды делятся на смысловые группы: несколько кодов могут быть **синонимами** одного правильного ответа (например, разные допустимые написания). Ввод любого синонима засчитывает всю группу.
Автор самостоятельно определяет:
- количество групп кодов (main-кодов) и синонимов внутри каждой группы;
- текст каждого кода;
- регистр символов;
- необходимость уникальности (в пределах уровня, см. ADR-0004).

---

# Количество необходимых групп кодов
Автор может указать, сколько из групп main-кодов необходимо решить для завершения уровня — это не обязательно все группы.

Пример.

```
Групп кодов (main-кодов) на уровне: 3
  Группа 1 (цвет радуги): красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый
  Группа 2 (месяц года): январь, февраль, ..., декабрь
  Группа 3 (первая буква алфавита): а

Необходимо решить групп: 2
```

Команда, введя «синий» (группа 1) и «декабрь» (группа 2), завершает уровень — группа 3 остаётся нерешённой и недоступна для дальнейшего ввода после завершения уровня. Другая команда может пройти этот же уровень, решив группы 2 и 3 вместо 1 и 2 — порядок и конкретный набор решённых групп не имеют значения, важно только их количество.

Если порог не задан явно — по умолчанию требуются **все** группы кодов уровня.

Подробная модель (main-коды, синонимы, порог, таксономия из 5 типов уровня) — ADR-0005, детали ввода — `code-submission.md`.

---

# Уровень без кодов
Level может вообще не содержать игровых кодов.
Такие уровни используются для сюжетных вставок, переездов, ожидания старта следующего этапа.
Прохождение подобных уровней возможно только по автопереходу — обязательному в этом случае (уровень без кодов и без автоперехода физически непроходим, это ошибка конфигурации, см. ADR-0005, «аномальный уровень»).

---

# Автопереход
Автор может задать время автоматического завершения уровня.

Например

```
30 минут
```

Если команда не выполнила условия прохождения, после истечения времени уровень завершается автоматически.

Причина завершения

```
AUTO_TRANSITION
```

---

# Первый уровень
Первый уровень обладает особым поведением.
Таймер первого уровня начинает отсчёт в момент старта Quest.
Если команда вошла позже, она получает только оставшееся время.
Если время автоперехода уже закончилось, уровень завершается сразу после входа команды в игру.
Это правило предотвращает получение преимущества за счёт позднего входа в игру.

---

# Последующие уровни
Для всех остальных уровней таймер начинает отсчёт в момент открытия уровня конкретной команде.
Автопереход каждого следующего уровня рассчитывается относительно времени его открытия.

---

# Подсказки
Level может содержать несколько подсказок.
Подсказки открываются автоматически
через заданное автором время.
Каждая подсказка имеет собственное время открытия.

---

# Типы подсказок
В текущей версии движка существуют три типа.

## Regular
Обычная подсказка.
Не влияет на итоговое время команды.

---

## Bonus
После получения может начислять бонусное время.

---

## Penalty
После получения может начислять штрафное время.

---

Конкретная логика начисления бонусов и штрафов определяется правилами Quest.

---

## LevelProgress

Во время прохождения Quest каждый Level порождает собственный `LevelProgress`.
`LevelProgress` хранит runtime-состояние прохождения уровня:
- время открытия;
- время завершения;
- время автоперехода;
- статус прохождения.

В дальнейшем `LevelProgress` будет связан с событиями ввода кодов, использованием подсказок, бонусами и штрафами.

---

# Инварианты
- Level принадлежит только одному Quest.
- Последовательность уровней неизменяема.
- Один Level может иметь множество Code.
- Один Level может иметь множество Hint.
- Один Level порождает один LevelProgress для каждой команды.
- Одновременно активным может быть только один LevelProgress.
- Следующий уровень открывается только после завершения предыдущего.
