# Quest Lifecycle

## Назначение
Данный документ описывает полный жизненный цикл Quest — от создания автором до завершения игры и формирования итоговой статистики.
Документ описывает последовательность событий системы, а не внутреннюю реализацию.

---

# 1. Создание Quest
Автор создаёт новый Quest.

Quest содержит:
- название;
- описание;
- дату и время старта;
- список уровней;
- правила игры;
- ограничения на количество команд;
- настройки регистрации.

После сохранения Quest находится в состоянии:

```
DRAFT
```

---

# 2. Подготовка Quest
Автор редактирует Quest.

Добавляет:
- уровни;
- игровые коды;
- подсказки;
- бонусы;
- штрафы;
- настройки автопереходов.

На этом этапе команды не могут подавать заявки.

---

# 3. Публикация
После завершения подготовки автор публикует Quest.

Статус Quest становится:

```
REGISTRATION
```

С этого момента начинается регистрация команд.

---

# 4. Регистрация команд
Капитан команды подаёт заявку.

Создаётся объект:
QuestRegistration

Статус регистрации:
```
PENDING
```

---

# 5. Подтверждение
Автор подтверждает заявку.

Статус становится
```
APPROVED
```

Только подтверждённые команды допускаются к игре.

---

# 6. Старт Quest
В момент наступления времени старта

Quest автоматически получает статус
```
RUNNING
```

Игровое время начинает отсчитываться.

Для всех подтверждённых команд создаётся:
QuestProgress

Одновременно создаётся первый LevelProgress.

---

# 7. Начало игры командой
Команда может открыть игру в любой момент после старта.
Если команда вошла позже, таймер не начинается заново.
Команда получает только оставшееся время первого уровня.
Это исключает получение преимущества за счёт позднего входа.

---

# 8. Прохождение уровня
Команда:
- читает задание;
- вводит коды;
- получает подсказки;
- выполняет условия прохождения.

Если введено необходимое количество правильных кодов, уровень завершается.

---

# 9. Автопереход
Если время уровня истекло, уровень автоматически завершается.
Создаётся следующий LevelProgress.

---

# 10. Последующие уровни
Все последующие уровни открываются последовательно.
Одновременно активным может быть только один LevelProgress.

---

# 11. Статистика
После каждого изменения QuestProgress статистика пересчитывается автоматически.
Во время игры отображается текущее положение всех команд.

---

# 12. Финиш
После завершения последнего уровня

QuestProgress получает статус
```
FINISHED
```

Фиксируются:
- игровое время;
- бонусы;
- штрафы;
- итоговое время.

---

# 13. Завершение Quest
После окончания игры автор переводит Quest в состояние
```
FINISHED
```

Команды, не завершившие прохождение, получают статус
```
DNF
```

---

# Итог
После завершения Quest становятся доступны:
- итоговая статистика;
- история прохождения;
- история уровней;
- результаты команд;
- аналитика игры.
