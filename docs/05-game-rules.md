# Старт игры
У всех команд старт игры происходит одновременно в момент времени Quest.startTime.

# Первый уровень
Первый уровень становится доступен с момента старта Quest.
Если команда входит позже, таймер первого уровня уже отсчитывается.
Поэтому команда может попасть на первый уровень с оставшимся временем автоперехода.

# Последующие уровни
Время всех следующих уровней начинает отсчитываться только после открытия уровня командой.
Автопереход второго уровня зависит исключительно от времени открытия второго уровня.

# Победитель
Побеждает команда, завершившая все уровни первой. После этого из общего времени игры команды отнимается заработанное в игре бонусное время, если есть, и прибавляется, если есть, штрафное время - это является окончаельным результатом игры команды.

# DNF
Если Quest завершён автором до того, как команда финишировала, команда получает статус DNF.
