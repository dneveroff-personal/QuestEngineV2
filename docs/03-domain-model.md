# Domain Model

## Overview

Quest Engine разделяет предметную область на два независимых мира.

- **Design-time** — объекты, создаваемые автором квеста.
- **Runtime** — объекты, создаваемые движком во время прохождения игры.

Такое разделение позволяет полностью отделить описание игры от процесса её прохождения.

---

# Design-time

Эти объекты создаются автором и являются шаблоном игры.

Во время прохождения игры они не изменяются.

```
Author
    │
    ▼
Quest
    │
    ├── Level
    │      ├── Code
    │      └── Hint
    │
    └── QuestRegistration
```

## Author

Создает Quest.

---

## Quest

Описание игры.

Содержит:

- общую информацию;
- время начала;
- время окончания;
- список уровней;
- зарегистрированные команды.

---

## Level

Описание игрового этапа.

Может содержать:

- текст задания;
- правильные коды;
- подсказки;
- время автоперехода;
- количество кодов, необходимых для прохождения.

---

## Code

Правильный ответ уровня.

---

## Hint

Подсказка уровня.

Может быть:

- обычной;
- бонусной;
- штрафной.

---

## QuestRegistration

Регистрация команды на Quest.

Хранит:

- команду;
- дату регистрации;
- статус регистрации.

После старта игры становится основой для создания QuestProgress.

---

# Runtime

Runtime-сущности создаются автоматически движком.

Каждая команда имеет собственный независимый набор Runtime-объектов.

```
QuestProgress
      │
      ├── LevelProgress
      │       │
      │       ├── CodeSubmission
      │       └── HintUsage
      │
      └── Team
```

## QuestProgress

Процесс прохождения Quest конкретной командой.

Хранит:

- команду;
- статус;
- текущий уровень;
- время старта;
- время завершения;
- список LevelProgress.

---

## LevelProgress

Процесс прохождения уровня конкретной командой.

Хранит:

- статус;
- время открытия;
- время завершения;
- найденные коды;
- использованные подсказки;
- начисленные бонусы;
- начисленные штрафы.

---

## CodeSubmission

Попытка ввода кода.

Создается при каждом вводе.

Сохраняется независимо от того, правильный код или нет.

---

## HintUsage

Факт получения подсказки.

Создается автоматически при открытии подсказки игроками.
